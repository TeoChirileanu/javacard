# Project Memory & Operating Rules

- **Regulă strictă de operare**: NU MAI TRIMITE COMENZI PE CARE NU LE EXECUTI SINGUR. Asistentul trebuie să execute el însuși comenzile de compilare, testare și verificare direct în mediul de execuție înainte de a raporta finalizarea către utilizator.
- **Interfață WinUI 3 (SmartCard.WinUI)**: Fereastra aplicației desktop trebuie să fie compactă (~600x680 px), cu `presenter.IsMaximizable = false`, `presenter.Restore()`, fără spații albe goale, iar conținutul să se potrivească perfect în fereastră.
